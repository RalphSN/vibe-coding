# OZ Space

一片空白的 3D 虛擬空間，只有人物（走、跑、跳、飛、推牆）和鏡頭，之後要在這裡做一個類似電影《夏日大作戰》OZ 那樣的原創虛擬世界（Vite + TypeScript + three.js）。人物、碰撞、鏡頭的程式從 `room-blockout/` 複製過來，房屋、家具、編輯器都拿掉了。

## 快速開始

需要 Node.js 20.19 以上或 22.12 以上（Vite 8 的要求，`node -v` 確認）。在 `oz-space/` 資料夾裡執行：

1. 安裝套件（第一次或 `package.json` 有變動時）：

   ```bash
   npm install
   ```

2. 啟動開發伺服器：

   ```bash
   npm run dev
   ```

3. 用瀏覽器打開終端機顯示的網址（預設 `http://localhost:5173/`）。

Windows（PowerShell）和 macOS（zsh）指令相同。直接雙擊 `index.html` 打不開，一定要透過開發伺服器或打包後的 `dist/`。

## 常用指令

| 指令 | 用途 |
|---|---|
| `npm run dev` | 開發伺服器，存檔後畫面自動更新 |
| `npm run build` | 先跑 `tsc` 型別檢查，再打包到 `dist/` |
| `npm run preview` | 在本機開啟打包好的 `dist/`，確認正式版能跑 |
| `npx tsc --noEmit` | 只跑型別檢查 |

## 專案結構

- `index.html`：頁面骨架（操作說明、第一人稱提示）
- `src/main.ts`：主程式（空白地面、碰撞、視角模式、角色、Inspector）
- `src/oz-props.ts`：各種環的樣式與周圍漂浮物（外觀、站得住的範圍、上下飄動）
- `src/config/scene.config.json`：所有可調數值（地面大小、出生點、角色、鏡頭）
- `src/config/scene.config.ts`：設定檔的型別、欄位說明與格式檢查
- `vite.config.ts`：含「儲存」用的 dev 外掛
- `src/style.css`：樣式
- `assets/raw/`：原始素材，只放本機、不進 git
- `assets/models/ual1-standard.glb`：角色模型與 43 段動畫（Quaternius Universal Animation Library Standard，CC0，授權見 `ual1-standard-LICENSE.txt`），用的是沒有根運動的版本
- `dist/`：`npm run build` 的輸出，不進 git

## 操作

開頁面時是第三人稱，站在出生點（`scene.spawn`）；`Tab` 切到環繞檢視，再按一次回到角色。

| 模式 | 按鍵 |
|---|---|
| 環繞檢視 | 拖曳環繞、滾輪縮放、右鍵平移、`Tab` 回到角色視角 |
| 第一人稱／第三人稱 | `W`／`S` 前進後退、`A`／`D` 轉身、`Q`／`E` 平移、空白鍵跳、連按兩下空白鍵飛行（空白鍵上升、`X` 下降，滑鼠雙鍵往前飛時順著鏡頭俯仰升降，碰到地面自動降落）、`Shift` 切換走路／跑步（預設跑步）、`Z` 切換加速（跑步 5 倍、飛行 10 倍，再按切回來）、`X` 坐下／站起來（不在飛行時；坐著時按方向鍵或空白鍵也會站起來）、滾輪切第三人稱、`Tab` 回環繞檢視 |

## 空間

目前是方塊稿：只用簡單形狀標出 OZ 世界的配置，比例以人物 1.83 m 為準。

| 部分 | 設定 | 預設 | 碰撞 |
|---|---|---|---|
| 地面 | `scene.groundSize` | 1200 m 見方，5 m 格線，四邊有隱形圍欄 | 走到邊緣被擋住（會播推牆動作） |
| 中央貓頭倒圓錐 | `scene.center` | 倒圓錐上面是平台（半徑 60 m、高 260 m），往下 240 m 收成尖點，尖點離地 20 m；平台上接一個半球（貓頭）和兩隻三角耳朵（內側粉紅），臉朝南（出生點那一側） | 圓錐側面和半球都用公式計算，碰撞面就是外觀表面；半球坡度不陡的地方走得上去；耳朵只有外觀 |
| 懸空的環（像星環） | `scene.rings` | 8 層，厚 2 m、寬 40 m；每層和上一層的高度差寫在 `layers[].gap`；每層內緣離圓錐側面都是 30 m，所以越往下直徑越小 | 見下表；從下面往上飛會撞頭，側面不擋 |
| 周圍漂浮物 | `scene.floaters` | 島嶼 12、各種形狀的平台 14、蜂窩狀六邊形平面 8、零碎小塊 60；約 8 成聚在 6 個聚集處，其餘零散；不碰到環、圓錐和貓頭 | 只有外觀，飛得過去 |
| 出生點 | `scene.spawn` | 最上面一圈環上（圓心南邊 100 m），面向北看著中央；高度自動落在該位置最高的表面 | — |

每層的樣式與間距在 `scene.rings.layers`（由上往下）：

| 層 | 樣式 | 頂面高度 | 外觀 | 站得上去 |
|---|---|---|---|---|
| 1 | `houses` | 238 m | 環面蓋滿房屋（斜屋頂，約 1/10 是平頂高樓），中間留一條 8 m 大街，出生點在街上 | 環面可以；房屋只有外觀，走得過去 |
| 2 | `broken` | 216 m | 1/3 是完整的環、斷口不規則；2/3 碎掉：從斷口往缺口中間，碎片由 10 m 漸漸變到 1.5 m，越來越稀、偏離越多、越歪，離開斷口一小段之後都在飄 | 完整那段可以；缺口不行 |
| 3 | `floatingBooks` | 190 m | 沒有環面，整層是不規則漂浮的書：攤開、半開、闔上，大小 0.6–4 m，大多是小本 | 不行 |
| 4 | `bookshelf` | 164 m | 空中圖書館：木地板上 4 圈 10 m 高的雙面書櫃（各 3 層），書櫃之間和內外兩側是約 5.5 m 寬的走道；每圈書櫃開 5 個 4.5 m 寬的缺口，可以穿到隔壁走道 | 地板可以；書櫃只有外觀 |
| 5 | `triple` | 142 m | 同一高度的內、中、外三層細環（各寬 10 m，間隔 5 m） | 三層各自可以 |
| 6 | `floatingHouses` | 108 m | 沒有環面，房屋歪歪斜斜漂在環的位置上；上下各留 34 m | 不行 |
| 7 | `shards` | 74 m | 全是各種形狀、顏色的碎塊 | 不行 |
| 8 | `restaurant` | 52 m | 環狀美食街：分成 8–12 區，每區一種擺法（攤位街、桌椅群、長桌區、植栽廣場），區和區之間留 5 m 走道；地面是低彩度的灰米色，每區疊一片不同色調的地面 | 環面可以；攤位、桌椅只有外觀 |

設計規則：蜂窩狀六邊形一律有一格是不同顏色（整個專案都適用，寫在 `oz-props.ts` 的 `addHexPad`）。

- 所有漂浮的東西（碎片、漂浮房屋、碎塊、島嶼、六邊形平面、小塊）都會上下飄，幅度約 0.3–1.5 m（`scene.floaters.bobScale` 倍率，0 是不動），每個的週期和起始時間不同。環本身不飄。
- 擺放用固定種子的亂數，每次重新整理長得一樣。
- 房屋、書、桌椅、碎片等裝飾放在 `world.decor`，第三人稱鏡頭不會為了避開它們拉近。
- 鏡頭可視距離跟著地面邊長（× 2.5）；環繞檢視第一次進來是從南邊高處俯瞰中央。
- 之後要加平台、建築或物件時，放進 `world.room` 並把碰撞加進 `world.colliders`（站上去、撞頭）與 `world.solids`（水平移動），寫在 `rebuildScene()`。坡道用 `world.ramps`，目前是空的。

## 人物與碰撞（從 room-blockout 沿用）

- 水平移動用膠囊體＋collide-and-slide：腳印是圓形，碰撞體是可以旋轉的方塊；撞到牆時貼著牆面滑。
- 比腳高「自動跨上高度」以內直接走上去，更高要跳。
- 按著方向鍵被牆擋住時切成推牆動作；手部 IK（兩骨反向動力學）讓兩隻手各自貼在牆面上。
- 側移時起跳，空中身體轉回正面。
- 飛行模式：沒有重力，漂浮姿勢是兩腳併攏垂下、膝蓋微彎、腳尖下垂，雙手微張；水平飛行時身體往行進方向傾，往下降到腳碰到地面就解除飛行，播落地動作。
- 走路和跑步用混合空間（blend space）：速度介於兩段動畫原速之間時按比例混合並對齊步伐，腳不會滑。
- 平移（`Q`／`E`）用方向扭轉（orientation warping）代替專用動畫：骨盆和腿轉向移動方向、上半身朝前。
- 模型載入失敗時，角色退回方塊人，錯誤寫在 console。

## Inspector（參數面板）

右上角的面板仿 Unity Inspector，分成三組，改了立刻生效：

| 分組 | 內容 |
|---|---|
| 場景 | 地面邊長；「中央倒圓錐」的平台半徑、平台高度、錐高；「懸空同心環」的離圓錐距離、每圈寬、厚度，以及每一層的樣式和離上一層的高度；「周圍漂浮物」的聚集處、島嶼、平台、蜂窩平面、零碎小塊數量與飄動幅度倍率 |
| 角色 | 縮放、碰撞半徑、走路／跑步／轉身速度、跳躍高度、重力；「動畫」裡有過渡秒數、動畫原速、落地硬直、顯示骨架、各動作用的動畫片段 |
| 鏡頭 | 第三人稱預設距離／俯仰／高度、第一人稱視角、靈敏度、縮放範圍、各種平滑時間 |

| 按鈕 | 做什麼 | 什麼時候有 |
|---|---|---|
| 儲存 | 把目前數值寫回 `src/config/scene.config.json`，舊檔先備份成 `scene.config.backup.json` | 只有 `npm run dev` |
| 還原預設 | 放棄還沒儲存的修改，回到上次儲存的內容 | 一直都有 |

## 還沒做

- 房屋、攤位、桌椅、圖書館書櫃、貓耳、漂浮物都沒有碰撞（先做外觀）；漂浮物要站得上去，需要「站在移動平台上被帶著走」的碰撞。
- 環的側面不擋人：從環的側邊水平飛進去會穿過去。
- 其他角色、多人、聊天等虛擬世界功能。
