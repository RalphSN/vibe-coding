# OZ Space

一片空白的 3D 虛擬空間，只有人物（走、跑、跳、飛、推牆）和鏡頭，之後要在這裡做一個類似電影《夏日大作戰》OZ 那樣的原創虛擬世界（Vite + TypeScript + three.js）。人物、碰撞、鏡頭的程式從 `room-blockout/` 複製過來，房屋、家具、編輯器都拿掉了。

## 快速開始

需要 Node.js 20.19 以上或 22.12 以上（Vite 8 的要求，`node -v` 確認）。在 `oz-space/` 資料夾裡執行：

1. 安裝套件（第一次或 `package.json` 有變動時）：

   ```bash
   npm install
   ```

2. 啟動開發伺服器：

   ```bash
   npm run dev
   ```

3. 用瀏覽器打開終端機顯示的網址（預設 `http://localhost:5173/`）。

Windows（PowerShell）和 macOS（zsh）指令相同。直接雙擊 `index.html` 打不開，一定要透過開發伺服器或打包後的 `dist/`。

## 常用指令

| 指令 | 用途 |
|---|---|
| `npm run dev` | 開發伺服器，存檔後畫面自動更新 |
| `npm run build` | 先跑 `tsc` 型別檢查，再打包到 `dist/` |
| `npm run preview` | 在本機開啟打包好的 `dist/`，確認正式版能跑 |
| `npx tsc --noEmit` | 只跑型別檢查 |

## 專案結構

- `index.html`：頁面骨架（操作說明，啟動時搬進 Inspector 的「操作說明」資料夾）
- `src/main.ts`：主程式（空白地面、碰撞、視角模式、角色、Inspector）
- `src/oz-props.ts`：各種環的樣式與周圍漂浮物（外觀、站得住的範圍、上下飄動），以及共用的合併網格、環境貼圖工具
- `src/oz-islands.ts`：周圍的漂浮島嶼（土塊本體、自然小島、6 座有用途的大島）
- `src/oz-cat.ts`：中央圓錐頂上的貓頭（頭、耳朵、貼著頭表面的五官、項圈）
- `src/oz-symbols.ts`：周圍漂浮的立體符號（用瀏覽器字型描輪廓再擠出）
- `src/oz-sports.ts`：最頂層的運動場（各種球場、壁球、拳擊、抱石、撞球）與兩側觀眾席
- `src/oz-gym.ts`：運動場裡的健身房
- `src/oz-kit.ts`：球場、健身房共用的建模小工具（加網格、桿子、canvas 貼圖與畫線）
- `src/oz-town.ts`：房屋環（街道與街景）與漂浮房屋環
- `src/oz-track.ts`：環形 PU 跑道（跑道標線、起跑器、欄架、步道的樹與休息區、販賣機）
- `src/oz-pool.ts`：環形游泳池（水面著色器、池底光紋、池畔設施）與天空環境貼圖
- `src/config/scene.config.json`：所有可調數值（地面大小、出生點、角色、鏡頭）
- `src/config/scene.config.ts`：設定檔的型別、欄位說明與格式檢查
- `vite.config.ts`：含「儲存」用的 dev 外掛
- `src/style.css`：樣式
- `assets/raw/`：原始素材，只放本機、不進 git
- `assets/models/ual1-standard.glb`：角色模型與 43 段動畫（Quaternius Universal Animation Library Standard，CC0，授權見 `ual1-standard-LICENSE.txt`），用的是沒有根運動的版本
- `dist/`：`npm run build` 的輸出，不進 git

## 操作

開頁面時是第三人稱，站在出生點（`scene.spawn`）；`Tab` 切到環繞檢視，再按一次回到角色。

| 模式 | 按鍵 |
|---|---|
| 環繞檢視 | 拖曳環繞、滾輪縮放、右鍵平移、`Tab` 回到角色視角 |
| 第一人稱／第三人稱 | `W`／`S` 前進後退、`A`／`D` 轉身、`Q`／`E` 平移、空白鍵跳、連按兩下空白鍵飛行（空白鍵上升、`X` 下降，滑鼠雙鍵往前飛時順著鏡頭俯仰升降，碰到地面自動降落）、`Shift` 切換走路／跑步（預設跑步）、`Z` 切換加速（跑步 5 倍、飛行 10 倍，再按切回來）、`X` 坐下／站起來（不在飛行時；坐著時按方向鍵或空白鍵也會站起來）；進到泳池自動游泳（抬頭蛙式，`W`／`S` 前後游、按住 `X` 下潛、按住空白鍵往上游，浮在水面時空白鍵跳出水面，往池邊游時按空白鍵就能跳上池畔，連按兩下飛走）、滾輪切第三人稱、`Tab` 回環繞檢視 |

## 人物與碰撞（從 room-blockout 沿用）

- 水平移動用膠囊體＋collide-and-slide：腳印是圓形，碰撞體是可以旋轉的方塊；撞到牆時貼著牆面滑。
- 比腳高「自動跨上高度」以內直接走上去，更高要跳。
- 按著方向鍵被牆擋住時切成推牆動作；手部 IK（兩骨反向動力學）讓兩隻手各自貼在牆面上。
- 側移時起跳，空中身體轉回正面。
- 飛行模式：沒有重力，漂浮姿勢是兩腳併攏垂下、膝蓋微彎、腳尖下垂，雙手微張；水平飛行時身體往行進方向傾，往下降到腳碰到地面就解除飛行，播落地動作。
- 走路和跑步用混合空間（blend space）：速度介於兩段動畫原速之間時按比例混合並對齊步伐，腳不會滑。
- 平移（`Q`／`E`）用方向扭轉（orientation warping）代替專用動畫：骨盆和腿轉向移動方向、上半身朝前。
- 模型載入失敗時，角色退回方塊人，錯誤寫在 console。

## 還沒做

- OZ 風格的原創視覺（天空、地面材質）；中央與環的本體還是方塊稿。
- 水面折射是畫面空間的近似：水面只能透出它後面已經畫出來、而且在水面以下的不透明物件（畫折射圖時會把水面以上切掉，水裡才不會出現人物的分身）。從水下往上看的水面是另一層半透明面（跟著波紋明暗起伏），沒有真的折射水面上的東西。
- 碎片、漂浮房屋、飄著的書、碎塊、符號用不轉的外框方塊當碰撞：頂面站得上去、會跟著上下飄，側面會擋。斜放的東西外框比實際大，站在上面可能會浮在最高點的高度；符號字裡的空洞也站得住。島嶼、平台、六邊形平面的碰撞照形狀算，和外觀相符。美食街的椅子不擋。
- 運動場的碰撞是外框方塊：斜放的抱石牆只擋底部，沙灘排球的木框與抱石護墊沒有碰撞（走進去會陷進去一點）；拳擊台、高起的看台長椅只能擋，不能站上去。
- 貓耳、貓臉、項圈、圓錐環帶、破碎環的碎石和交通錐、島上的樹冠、草叢、帳篷營繩、瀑布沒有碰撞（只有外觀）；島上的樹只有樹幹會擋。
- 立體符號用瀏覽器的系統字型畫：不同電腦（Windows／macOS）的字形會略有不同；系統沒有某個字的字型時，那個符號會跳過不放。
- 環的側面不擋人：從環的側邊水平飛進去會穿過去。
- 其他角色、多人、聊天等虛擬世界功能。
