# 視覺規格

所有數值都來自 `assets/template.html`，改之前先在範本裡找到對應的 CSS。

## 1. 頁面結構

由上到下只有四塊，不加 hero、標語或行銷文案：

1. 頂部列（48px）：品牌圖示＋名稱＋等寬字路徑（`~/course-web`，寬度 < 480px 時隱藏路徑）、右側「自動／淺色／深色」切換。
2. 標題列：`書櫃`（clamp 28–40px、字距 0.04em）＋右側等寬統計 `2 本 · 79 單元 · 已讀 0`。
3. 書櫃：背板＋書＋書擋＋層板。
4. 說明欄：游標停在書上或 Tab 聚焦時顯示標題、簡介、路徑、內容、狀態、已讀、查證；平常顯示操作提示。≥ 768px 兩欄，以下一欄。

`main` 垂直置中，頁尾一行「進度只存在這個瀏覽器。」

## 2. 色彩與字體

| Token | 淺色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#f5f5f7` | `#000000` | 頁面底色 |
| `--text` / `--text-2` | `#1d1d1f` / `#6e6e73` | `#f5f5f7` / `#a1a1a6` | 文字（兩組對比都 ≥ 4.5:1） |
| `--focus` | `#0071e3` | `#2997ff` | 焦點框 |
| `--paper` / `--paper-2` | `#f8f4ea` / `#efe8d8` | 同左 | 紙、蝴蝶頁（書是實物，深色模式不反轉） |
| `--foil` | `#efe2bf` | 同左 | 燙金字、壓條細線、進度線 |

書布顏色：深而飽和，白底和黑底上都要像實體書。目前用寶藍 `#1e4fb3`、墨綠 `#1d6338`；新書建議酒紅 `#7a1f2b`、深棕 `#5a3a1e`、石墨 `#2f3438`、深紫 `#3d2a6b`（未實測，加入後要看燙金字對比）。

字體：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Inter", "PingFang TC", "Noto Sans TC"`；等寬 `"SF Mono", "JetBrains Mono"`。Google Fonts 載入 Inter、JetBrains Mono、Noto Sans TC。

字距：中文一律 ≥ 0。內文 `0.01em`、行高 1.6；說明欄內文行高 1.7；書背直排 `0.14em`；`dt` 標籤 `0.08em`。

## 3. 書背（.spine）

從後到前疊四層，順序不能錯：

1. 書布底色 `var(--accent)`。
2. 布紋 `--linen`：兩組 1px、間距 3px 的重複漸層（水平白 4.5%、垂直黑 6%）。
3. 圓弧明暗：`linear-gradient(90deg, 黑50% 0, 黑14% 7%, 白16% 22%, 白5% 40%, 黑6% 64%, 黑30% 90%, 黑55% 100%)`，高光偏左代表光從左上來。
4. 內容（grid：壓條／圖示／書名標籤／底部數字／壓條）。

元件：
- 壓條 `.band`：高 7px，上下各一條燙金 1px 細線（55% 透明），中間凸起的明暗漸層。
- 書名標籤 `.spine-label`：黑 26% 底、燙金 1px 細框、內陰影，像貼上去的皮標。
- 書名 `.spine-title`：`writing-mode: vertical-rl`、15px、600、燙金色、浮雕陰影 `0 -1px 0 黑50%, 0 1px 0 白14%`。
- 圖示 22px、燙金、`drop-shadow(0 -1px 0 黑45%)`。
- 底部 `.spine-foot`：等寬 11px，完成顯示 `29 課`，製作中顯示 `25/50`。
- 進度線 `.spine-progress`：右側 2px 寬、燙金填色，高度＝已讀比例。

## 4. 書櫃

- 背板 `.bookcase`：上淺下略深的漸層，三道內陰影（上方 26px 代表上層板的影子、左右 14px），上方圓角 10px。
- 層板 `.board`：高 20px，頂面 6px 的亮金屬帶＋正面拉絲（1px/3px 重複漸層）＋下方投影；左右用負 margin 延伸到背板邊緣。
- 書 `margin-bottom: -3px`，站進層板頂面一點，避免看起來浮著。
- 書擋：SVG L 形，金屬水平漸層 `#9c9ca4 → #f2f2f5 → #c4c4cb → #8e8e96`，左緣一道白色高光線，`drop-shadow` 投在右側。

## 5. 陰影

光源固定在左上：
- 書投到背板：`box-shadow: 12px 2px 18px -10px 黑55%`。
- 接觸陰影 `.book-contact`：書底下 10px 高的橢圓 radial-gradient。hover 時書上移 12px，接觸陰影反向下移 12px、放寬 1.15 倍、透明度 0.45，看起來留在層板上。

## 6. 開書舞台的材質

- 書板（封面、封底、右頁的底板）用 `.cloth`：斜向高光＋布紋＋書布色。
- 封面正面：靠書脊 6cqw 處一道折痕、5cqw 內縮的燙金外框、左上圖示、右上單元數、左下書名（詞組換行）與 `VIBE CODING · 年月`（不換行）。
- 紙 `.paper`：上方淡淡的反光＋紙色。書口與上下書頂用 1px/2px 的重複漸層畫紙頁。
- 書溝：`.gutter-left` / `.gutter-right` 內陰影 14px，靠書脊那側。
- 蝴蝶頁 `.endpaper`：書布色 16% 的 0.8px 細點，間距 10px。

## 7. 不要再犯（使用者回饋過的問題）

| 問題 | 原因 | 規則 |
|---|---|---|
| 「看起來只是色塊」 | 書背只有平塗色 | 第 3 節四層都要有 |
| 「字跟字之間太近」 | 對中文用了 -0.01 到 -0.03em | 中文字距 ≥ 0 |
| 書頂露出的紙頁「很不自然、透視完全錯誤」 | 正視圖裡畫了俯視才看得到的面 | 書櫃上不畫任何頂面 |
| 書名被截成「Prompt × Agent 實」 | 書櫃太矮、字距太大 | 書櫃高 `clamp(340px, 36vw, 360px)`＋`fitSpineTitles()` |
| 手機頂部列「Vibe Coding」擠成兩行 | 路徑文字太長 | 品牌 `white-space: nowrap`，< 480px 隱藏路徑 |
| 封面「VIBE CODING · 2026-10」斷行 | 窄封面放不下 | `white-space: nowrap`、字級下限 8px |
