# 教材與課程

## 每課固定結構

依序六段，不跳段：
1. 比喻：用日常生活的東西說明這個概念；接著一句寫出比喻的限制（哪裡不像）。
2. 心智模型：用一張圖或一段話說明「它在腦中應該長什麼樣」。
3. 正式定義：精確的術語定義，術語中英並列。
4. 程式碼或範例：先給一個完整解說的範例（worked example），再給一個讓讀者補完的半成品。
5. 常見錯誤：至少 3 個，每個寫「錯誤寫法 → 為什麼錯 → 正確寫法」。
6. 三個重點：剛好 3 條，每條一句。

## 對零基礎與 ADHD 友善

- 每課 20–30 分鐘；標題下方標註「閱讀時間：約 N 分鐘」。
- 每課只教一個核心概念；超過就拆成兩課。
- 段落最多 3 句；每 300–400 字就要有標題、圖、程式碼或練習打斷。
- 第一次出現的術語都要解釋，不假設讀者已經知道。
- 每課開頭寫「學完你能做到：___」，一句話。

## 練習題

- 每課至少 3 題，難度遞增：回想 → 應用 → 遷移到新情境。
- 不出只考背誦的是非題；題目要讓讀者動手寫、預測輸出或找錯。
- 每題的答案和解析先藏起來，讀者想過再展開：Notion 用 toggle，HTML 用 `<details><summary>`。
- 解析寫「為什麼」，並指出最常見的錯誤答案錯在哪。

## 學習科學

- 間隔回想：每課開頭放 1–2 題前幾課的回顧題（答案一樣藏起來）。
- 具體先於抽象：先看例子，再給規則。

## 視覺與互動

- 有流程、結構、空間關係時，用 SVG 圖解，不只靠文字。
- 有「改變參數會怎樣」的概念時，做 JS 互動示範（滑桿、按鈕）。
- 3D 概念（座標、旋轉、相機）用 Three.js 示範。
- 互動示範要能用鍵盤操作，並處理 `prefers-reduced-motion`。

## 輸出格式

Notion 版：
- 一課一頁；頁面標題「第 N 課：主題」。
- 用 callout 放「學完你能做到」與閱讀時間。
- 練習答案用 toggle；程式碼用 code block 並指定語言。

單一 HTML 版：
- 一個 `.html` 檔，CSS 與 JS 內嵌，外部函式庫只從 CDN 載入。
- 手機寬度可讀；支援深色模式（`prefers-color-scheme`）。
- 練習答案用 `<details>`；圖解用內嵌 SVG。
- 頁首放目錄連結到各段。
