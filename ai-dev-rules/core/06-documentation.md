# 文件

所有文件都照「溝通規範」寫：結論先行、短段落、可跳讀。

## README 結構

依序包含：
1. 一句話說明這是什麼
2. 快速開始：安裝與啟動指令，3 步以內
3. 常用指令表：指令 | 用途
4. 專案結構：只列重要資料夾，一行一個
5. 環境變數：名稱 | 用途 | 範例值（不放真值）

## 程式碼內文件

- 匯出的函式、元件、公開 API 寫 JSDoc / XML doc：用途、參數、回傳值、可能拋出的錯誤。
- 內部實作只在「為什麼」不明顯時寫註解。

## API 文件

每個端點寫：方法與路徑、用途、請求參數、回應範例、錯誤碼。有 OpenAPI 就以 OpenAPI 為準。

## 變更紀錄

- `CHANGELOG.md` 用 Keep a Changelog 格式：`Added`、`Changed`、`Fixed`、`Removed`。
- 最新版本放最上面，每筆一行，寫使用者看得到的影響。
