# 影片分鏡表

## 步驟

1. 確認基本資訊：用途、平台與比例（YouTube 16:9、Shorts / Reels 9:16）、總長度、風格、有沒有旁白。
2. 寫一句話的影片主旨，和開頭 3 秒的鉤子。
3. 照範本寫分鏡表；每個鏡頭 2–6 秒，秒數加總等於總長。
4. 停下來等使用者確認分鏡表；確認後才產生每個鏡頭的生成 prompt 或剪輯清單。

## 範本

```
影片：<標題>
主旨：<一句話>
比例：9:16　總長：30 秒　風格：<風格>

| 鏡號 | 秒數 | 畫面 | 運鏡 | 音效 / 音樂 | 字幕 / 旁白 |
|---|---|---|---|---|---|
| 1 | 0–3 | <鉤子畫面> | 推 | <音效> | <字幕> |
| 2 | 3–8 | ... | 固定 | ... | ... |
```

## 規則

- 運鏡只用：固定、推、拉、搖、移、跟、升降、手持。
- 字幕每行最多 16 個中文字，一個鏡頭最多兩行。
- 每個鏡頭的畫面描述要能直接轉成生成 prompt：主體、動作、場景、光線。
- 音樂與音效寫明授權來源，或標「待找」。
- 同一角色跨鏡頭時，寫一段固定的角色描述，每個鏡頭的 prompt 都附上，維持一致。
