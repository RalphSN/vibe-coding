# 圖片生成 prompt

## 步驟

1. 確認用途與平台：網頁橫幅、社群貼文、簡報、遊戲素材；用哪個生成工具（不同工具語法不同）。
2. 缺少的關鍵資訊只問一個最重要的；其他用合理預設並標明。
3. 依 7 項結構寫 prompt。
4. 輸出一個主版本，加 2 個變體（改風格或構圖），讓使用者挑。

## 輸出格式

```
用途：<用途>，比例 <16:9>

主體：<誰或什麼、動作、外觀細節>
風格：<媒材、畫風、參考年代>
構圖：<景別、視角、主體位置、留白位置>
光線：<光源、時間、氛圍>
色彩：<主色、配色>
比例：<16:9>
負面提示：<不要的東西>

英文 prompt（直接貼到工具）：
<一段英文，依上面順序組合>

變體 A：<改了什麼>
變體 B：<改了什麼>
```

## 規則

- 不寫「高品質」「傑作」「8K」這類沒資訊量的詞。
- 不用在世藝術家的名字當風格；不要求重製受版權保護的角色或商標。
- 要放文字的圖（橫幅、封面），在構圖寫明留白位置，文字之後再用設計工具加。
- 遊戲素材寫明背景（透明或純色）與視角（側視、俯視、等角）。
