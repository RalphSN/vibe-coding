# 課程架構：AI 系列・序章｜AI 全景地圖

> 版本：v1（2026-10-22）・ 依據：`research-notes.md`
> **4 個模組、14 個單元**，每單元 7–12 分鐘，總閱讀約 2 小時
> 對象：任何想搞懂「AI 到底是什麼、我該學到多深」的人；不需要會寫程式
> 學完的狀態：說得出 AI、機器學習、深度學習、LLM 的包含關係；能從頭講一遍「按下送出到出現回答」中間發生什麼；知道自己要走哪條路線、每一卷要讀到 L1、L2 還是 L3

---

## A. 全站學習設計

### A-1 每個單元的固定結構

同第一部：3 件事 → 暖身回顧 → 比喻＋限制 → 心智模型 SVG → 正式定義 → 範例 → 3 個常見錯誤 → 3 題練習 → 三個重點 → 來源。

### A-2 全書主軸：從按下送出到出現回答

六站：**你的電腦 → 後端 → API → tokenizer → GPU 上的模型 → 回到螢幕**。每課標題上方標出自己在哪幾站（`JOURNEY`，模組 2 逐課標示）。

### A-3 取捨

| 項目 | 做法 | 理由 |
|------|------|------|
| 深度 | 每個主題只講到 L1：知道是什麼、和其他東西的關係；細節一律指向其他卷 | 序章是地圖，不是教科書 |
| 程式碼 | 幾乎沒有；只在 2-1 放一段請求 JSON 讓讀者認得 | 對象不一定會寫程式 |
| 數字 | 只放查證過的歷史數字；中文 token 數不寫，叫讀者用 count_tokens | 第三方估計差異太大 |
| L1／L2／L3 | 本書自訂並明講 | 使用者大綱只給名稱 |
| 和第一部重疊 | 模組 2 的 API、token、串流細節連到第一部對應課 | 不重複 |

### A-4 間隔複習

| 正在讀 | 暖身題來自 |
|------|------|
| 模組 1 | 0 |
| 模組 2 | 1 |
| 模組 3 | 2、1；3-3 是總複習（10 題） |

### A-5 互動元件

| 元件 | 讀者做什麼 | 動畫？ | 出現位置 |
|------|------|------|------|
| `classify` | 分類練習 | 靜態 | 0-1、1-1、1-2、1-3、1-5、3-1、3-2 |
| `sampler`（新） | 看下一個 token 的機率長條，拉 temperature、按「抽一個」把字接上句子 | 靜態（每按一次真的抽一次） | 1-4、2-4 |
| `ragtrace`（改名「逐站追蹤」） | 一站一站走過請求的旅程 | 步進 | 2-1 |
| `tokenmeter` | 看文字被切成幾段（示意） | 靜態 | 2-2 |
| `knobs` | CPU 與 GPU 平行運算的時間（示意） | 靜態 | 2-3 |
| `ssestream`、`costcalc` | 看等待與花費發生在哪 | 串流是動畫 | 2-5 |
| `checklist` | 自我評估目前在哪一層 | 靜態 | 3-3 |

## B. 模組與單元

### 模組 0　這張地圖怎麼用（`--m0`）
- **0-1 為什麼|先看地圖**：七卷各回答什麼問題、建議的讀法。圖：七卷地圖；問題→卷對照。互動：classify（這個問題去哪一卷）

### 模組 1　AI、ML、DL、LLM：一組俄羅斯套娃（`--m1`）
- **1-1 AI：|最外層的娃娃**：AI 是目標不是技術；規則式 vs 學習式。圖：套娃；規則式與學習式對照。互動：classify
- **1-2 機器學習：|從資料學出規則**：資料、模型、評分；Samuel 1959 下棋程式。圖：寫規則 vs 學規則；學習迴圈。互動：classify（是不是 ML）
- **1-3 深度學習：|多層網路自己找特徵**：特徵工程 vs 自己學特徵；2012 AlexNet 與 GPU。圖：多層網路；傳統 ML vs DL。互動：classify
- **1-4 LLM：|會接話的深度學習**：預測下一個 token；Transformer、預訓練＋後訓練；生成式 AI 與多模態的位置。圖：接話；LLM 在套娃裡的位置。互動：sampler
- **1-5 七十年|時間軸**：1955 Dartmouth → 1959 Samuel → 2012 AlexNet → 2017 Transformer → 2020 GPT-3 → 2022 ChatGPT。圖：時間軸；每層出現的年代。互動：classify（事件歸到哪個時代）

### 模組 2　從按下送出到出現回答（`--m2`）
- **2-1 全程鳥瞰：|一個問題經過的六站**：六站與各站負責的事。圖：六站；請求 JSON。互動：ragtrace
- **2-2 第一站之後：|文字變 token**：tokenizer、編號、為什麼按 token 計費。圖：文字→token→編號；同句不同切法。互動：tokenmeter
- **2-3 GPU 上的|一次計算**：模型＝一大堆數字；一次前向計算＝很多矩陣乘法；為什麼用 GPU。圖：CPU vs GPU；一次計算的流程。互動：knobs
- **2-4 一個字|一個字長出來**：自迴歸、機率、取樣；第一個字最慢的原因（KV cache 預告）。圖：自迴歸迴圈；每一步的機率長條。互動：sampler（多步）
- **2-5 回到螢幕：|時間與錢花在哪**：串流、TTFT、按 token 計費；把六站串成一張帳單。圖：時間組成；花費組成。互動：ssestream＋costcalc

### 模組 3　學習地圖（`--m3`）
- **3-1 三種「懂」：|L1、L2、L3**：會用、會做、會推導；同一個主題的三層。圖：三層；同一主題的三種問題。互動：classify
- **3-2 七卷地圖：|每卷教什麼、到哪一層**：七卷主題、主要層級、先修關係。圖：七卷依賴圖；層級表。互動：classify
- **3-3 選一條路線|＋總複習**：三條路線（應用開發、懂原理、研究與硬體）；10 題總複習。圖：三條路線。互動：checklist＋quiz

## C. 數量目標

- 圖：14 課 × 2 ＝ 28 張以上。
- 選擇題：每課 3–4 題，加 3-3 總複習 10 題，約 60 題；正確答案是最長選項 ≤ 35%。
