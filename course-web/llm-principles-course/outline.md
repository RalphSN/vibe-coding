# 課程架構：AI 系列・第二部｜大型語言模型原理

> 版本：v1（2026-10-22）・依據：`research-notes.md`
> **8 個模組、28 個單元**，每單元 7–12 分鐘
> 對象：讀過序章、想知道 LLM 裡面在做什麼的人；不需要會寫程式，數學卡住翻隨身卷
> 學完的狀態：能從頭講一遍「一段文字怎麼變成下一個 token」，手算一個小 attention，說得出預訓練、後訓練、推論各自在做什麼，解釋幻覺為什麼會發生

## 主軸：一段文字在模型裡的六站

文字 → token 編號 → 向量 → Transformer 區塊 → 下一個 token 的機率 → 取樣與輸出（`JOURNEY`）

## 取捨

| 項目 | 做法 | 理由 |
|---|---|---|
| Claude 內部 | 不寫層數、參數、資料量 | 沒有公開 |
| 數學 | 只到手算 3×3 的小例子；公式都附白話 | 對象不一定會線性代數 |
| 程式碼 | 少量 Python 示意（NumPy 風格），不需要執行 | 讓 L2 讀者對照 |
| 第四部重疊 | 反向傳播、優化器只講「預訓練在調參數」，細節連到第四部 | 不重複 |

## 間隔複習

模組 N 的暖身題來自 N−1 與更早一個模組；7-5 總複習 12 題。

## 模組

- 0 一段文字在模型裡的路：0-1
- 1 Tokenization：1-1 為什麼不用字或字母、1-2 BPE、1-3 詞彙表大小、1-4 特殊 token 與對話格式
- 2 Embedding：2-1 查表、2-2 相似度、2-3 位置
- 3 Attention：3-1 每個字在看誰、3-2 Q K V、3-3 縮放點積與 softmax、3-4 因果遮罩與多頭
- 4 Transformer：4-1 block、4-2 殘差、4-3 layer norm、4-4 參數在哪
- 5 預訓練：5-1 損失、5-2 資料、5-3 規模定律
- 6 後訓練：6-1 SFT、6-2 RLHF 與 DPO、6-3 原則與安全、6-4 推理模型
- 7 推論：7-1 取樣、7-2 context window、7-3 KV cache、7-4 幻覺、7-5 總複習
