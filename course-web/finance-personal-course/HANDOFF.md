# 交接：理財系列・第一部｜個人財務

狀態：17 課完成並上架（2026-10-29），未 commit，在分支 `feat/finance-personal-course`。

## 規格

- 使用者指定：不放考題（沒有 review、practice、tryit、quiz），只放深入理論與試算。
- 每課：3 件事 → 比喻 → 心智模型 → 定義 → 詳細說明（含「深入」小節）→ 常見錯誤 → 三個重點 → 參考資料。
- e-engine1 的 `examples` 段落標題改為「詳細說明」；系列選單改「理財系列」，卷數用 `SERIES.volumes.length`。
- compare 區塊是為提示詞設計的（字串、有複製鈕），本卷改用兩欄表格＋「差在哪裡」callout。

## 結構

| 模組 | 課 | 主要試算 |
|---|---|---|
| 0 起點 | 0-1 | 水塔模型（現金流、撐幾個月） |
| 1 看見你的錢 | 1-1～1-4 | 偶發支出攤提、反推法、儲蓄率、資產負債表 |
| 2 預算與行為 | 2-1、2-2 | 零基預算、小錢 vs 大石頭、加薪分配 |
| 3 緊急預備金 | 3-1、3-2 | 預備金目標、實質購買力 |
| 4 債務的本質 | 4-1～4-4 | 貸款月付、槓桿、卡債還款、額度使用率 |
| 5 還債 | 5-1～5-3 | 雪崩 vs 雪球、負債收入比、房貸壓力測試、債務整合 |
| 6 串起來 | 6-1 | 我在第幾階、年度健檢清單 |
