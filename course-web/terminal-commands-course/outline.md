# 課程架構：終端機指令，從零看懂到會寫

> 版本：v1（2026-10-07）・ 依據：`research-notes.md`
> **9 個模組、37 個單元**，每單元 6–12 分鐘，總閱讀約 5–6 小時
> 對象：完全沒有用過終端機的初學者；Windows 為主、macOS 並行
> 學完的狀態：看到陌生指令能拆解出「誰、做什麼、怎麼做、對誰做」，能自己寫出常見的檔案、管線、git、npm 與 AI CLI 指令；知道自己還不懂的部分叫什麼名字、去哪裡查（從「未知的未知」到「已知的未知」）

## A. 全站學習設計

### A-1 每個單元的固定結構

照 `course-web-neo-brutalism` 的 `content-rules.md`：3 件事 → 暖身回顧 → 比喻＋限制 → 心智模型 SVG → 正式定義 → 對照範例＋半成品 → 3 個常見錯誤 → 3 題練習（回想／應用／遷移）→ 三個重點 → 來源。

### A-2 全課主軸：指令的四個位置

每一課都回到同一個拆解法：

```
git      commit     -m "修正登入"     src/login.js
誰       做什麼      怎麼做             對誰做
(程式)   (子指令)    (選項)             (參數)
```

加上「連接符號」（`|`、`>`、`&&`）把多個指令接成一句。看懂這五種東西，就看得懂九成的指令。

## B. 模組與單元

格式：`ID 標題（| 為斷點）`・目標・圖 1／圖 2

### 模組 0　終端機是什麼（`--m0`）
- **0-1 終端機、shell|與作業系統**：分清三層。圖：三層架構；term 播放第一個指令。
- **0-2 打開你的|第一個終端機**：在 Windows／macOS 打開終端機，認出自己用的是哪個 shell。圖：四種提示字元；開啟步驟。
- **0-3 提示字元|與救命按鍵**：提示字元不是指令的一部分；Tab、↑、Ctrl+C、清除畫面、複製貼上。圖：提示字元解剖；按鍵地圖。

### 模組 1　核心邏輯：指令的文法（`--m1`）
- **1-1 指令的解剖：|程式、選項、參數**：四個位置。anatomy 元件；長短選項對照圖。
- **1-2 空白、引號|與跳脫字元**：空白是分隔符號；單雙引號差別；三種跳脫字元。
- **1-3 看懂說明：|--help 與 man**：讀 usage 語法 `[ ] < > ...`；各 shell 的說明指令。
- **1-4 結束代碼|與錯誤訊息**：0 是成功；`$?`、`$LASTEXITCODE`、`%ERRORLEVEL%`；四種最常見的錯誤訊息。

### 模組 2　檔案系統與路徑（`--m2`）
- **2-1 路徑：|絕對與相對**：樹狀結構、`/` 與 `\`、`~`、`.`、`..`。fstree。
- **2-2 移動與查看：|cd、ls、pwd**：fstree 互動；PowerShell 別名。
- **2-3 建立、複製、|移動、刪除**：`mkdir`、`cp`、`mv`、`rm`；`rm` 沒有資源回收筒；萬用字元。
- **2-4 讀檔與搜尋：|cat、grep、find**：讀檔、找檔名、找內容的三種工具。

### 模組 3　資料流：管線與重新導向（`--m3`）
- **3-1 三條水管：|stdin、stdout、stderr**：pipeflow；錯誤訊息為什麼沒有進檔案。
- **3-2 管線 |：|把指令接起來**：pipeflow；文字管線 vs 物件管線。
- **3-3 重新導向：|>、>>、2>**：覆寫與附加；丟掉輸出的地方（`/dev/null`、`$null`、`NUL`）。
- **3-4 串接指令：|成功才繼續、|失敗才執行**（`&&`、`||`、`;`）：成功才繼續、失敗才執行、不管結果；PowerShell 5.1 的限制。

### 模組 4　環境：變數、PATH、權限（`--m4`）
- **4-1 環境變數**：讀、設定、暫時與永久。
- **4-2 PATH：|系統怎麼找到指令**：pathfinder；`which`、`where.exe`、`Get-Command`；修好「找不到指令」。
- **4-3 權限：|sudo 與系統管理員**：rwx 與 `chmod +x`；Windows 系統管理員終端機、UAC、Windows 的 sudo；PowerShell 執行原則。
- **4-4 設定檔：|.zshrc 與 $PROFILE**：啟動時自動執行的檔案；alias；重新載入。

### 模組 5　三大 shell 方言＋cmd（`--m5`）
- **5-1 bash：|伺服器與教學的通用語**：Linux、WSL、Git Bash；shebang 與第一個腳本。
- **5-2 zsh：|macOS 的預設 shell**：和 bash 九成相同；提示字元 `%`；`.zshrc`。
- **5-3 PowerShell：|傳的是物件**：動詞-名詞、物件管線、別名、5.1 vs 7。
- **5-4 cmd：|認得舊式指令**：`dir`、`copy`、`del`、`%VAR%`、`.bat`；在舊教學裡認出它。
- **5-5 同一件事|四種寫法**：rosetta；判斷一段指令是哪一種方言的線索。

### 模組 6　跨平台必備工具（`--m6`）
- **6-1 套件管理器：|winget、brew、apt**：用一行指令安裝軟體。
- **6-2 git：|存檔點的指令**：clone、status、add、commit、push、pull。
- **6-3 Node.js：|npm 與 npx**：`npm install`、`npm run`、`npx`、package.json。
- **6-4 Python：|pip 與虛擬環境**：`python`／`python3`／`py`、`pip`、venv 在四種 shell 的啟用方式。
- **6-5 curl 與 ssh：|和網路說話**：下載、呼叫 API、登入遠端主機。

### 模組 7　三大 AI 工具的終端機指令（`--m7`）
- **7-1 AI CLI 的|共同結構**：安裝 → 登入 → 互動／非互動 → 權限模式 → 斜線指令 → 專案說明檔。
- **7-2 Claude Code：|claude 指令**
- **7-3 Codex CLI：|codex 指令**
- **7-4 Antigravity CLI：|agy 指令**（含 Gemini CLI 轉換說明）
- **7-5 看懂 AI|要你執行的指令**：用 anatomy 拆解 AI 提出的指令再決定是否允許。

### 模組 8　安全與總複習（`--m8`）
- **8-1 危險指令|辨識手冊**：刪除、覆寫、提權、下載即執行、強制推送。
- **8-2 指令速查表**（reference）：依任務分類的四方言對照。
- **8-3 總複習測驗**（reference）：15 題＋拆解挑戰。
