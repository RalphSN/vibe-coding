# 設計系統：終端機指令，從零看懂到會寫

> 版本 v1（2026-10-07）。規格來源：`course-web-neo-brutalism` skill 的 `design-tokens.md`、`components.md`、`line-breaking.md`。
> 引擎與基礎 token 沿用 `claude-code-secure-dev-course/`（已通過 skill 全部檢查），這份只記錄本站新增的決定與檢查結果。

## 1. 主題方向

「工地告示牌 × 手作貼紙本」的新野獸派骨架不變，加上**終端機**的元素：

- 品牌字樣 `>_ 終端機指令` 後面有閃爍的方塊游標（reduced-motion 時不閃）。
- 首頁 hero 右側是一個會逐字打字的終端機，打完後把指令拆成彩色零件，直接示範整門課的核心方法。
- 所有範例畫面都是深色終端機（`#111111`），綠色提示字元、白色指令、米色輸出、紅色錯誤。
- **指令零件色**：全站固定一組顏色代表五種零件，圖、互動元件、速查表都一致。

## 2. 色彩 token

模組色、語意色沿用參考站（對比檢查見參考站 design-system.md）。新增：

| Token | 值 | 用途 |
|---|---|---|
| `--k-prog` | `var(--m1)` 粉紅 | 程式 |
| `--k-sub` | `var(--m2)` 藍 | 子指令 |
| `--k-opt` | `var(--m4)` 橘 | 選項 |
| `--k-arg` | `var(--m3)` 綠 | 參數 |
| `--k-op` | `var(--m0)` 黃 | 連接符號 |
| `--k-var` | `var(--m5)` 紫 | 變數 |
| `--term-prompt` | `#7CE577` | 終端機提示字元 |
| `--term-err` | `#FF8F8F` | 終端機錯誤輸出 |
| `--term-dim` | `#A3A3A3` | 註解、次要輸出 |

零件色塊上一律黑字（`--on-color`），對比沿用模組色的檢查結果（最低 `--m2` 8.06:1）。

## 3. 對比檢查（2026-10-07，WCAG 2.x 公式）

| 組合 | 比值 | 標準 |
|---|---|---|
| 提示字元 `#7CE577` × `#111111` | 11.99 | ≥ 7 ✓ |
| 錯誤輸出 `#FF8F8F` × `#111111` | 8.61 | ≥ 7 ✓ |
| 次要輸出 `#A3A3A3` × `#111111` | 7.49 | ≥ 7 ✓ |
| 一般輸出 `#F2F0E6` × `#111111` | 16.53 | ≥ 7 ✓ |
| 指令 `#FFFFFF` × `#111111` | 18.88 | ≥ 7 ✓ |
| 黑字 × 進行中底色 `--highlight` | 17.05 | ≥ 7 ✓ |

SVG 裡的終端機畫面用 class（`fill-term`、`t-prompt`、`t-cmd`、`t-out`、`t-dim`、`t-err`）上色，不用 `fill="#…"` 屬性，否則會被 `.figure svg text` 的預設色蓋掉。

## 4. 新增元件

| 元件 | 說明 | 動畫 | reduced-motion |
|---|---|---|---|
| `term` | 逐步播放的終端機：逐字打字、輸出淡入、右側說明 | 打字（34ms／字）、輸出上移淡入 | 直接顯示，自動播放停用 |
| `anatomy` | 指令拆解器：預設範例＋自由輸入，零件依序落下 | 每塊延遲 70ms 落下 | 無動畫 |
| `fstree` | 資料夾樹＋模擬終端機（cd、ls、pwd），目前位置與路徑軌跡同步 | 底色轉場 | 只保留顏色 |
| `pipeflow` | 直向輸送帶：每站指令與流出的資料，逐站播放 | 資料行依序滑入 | 無動畫 |
| `pathfinder` | PATH 搜尋：依序檢查每個資料夾，找到即停 | 每 650ms 檢查一格 | 一次顯示結果 |
| `rosetta` | 四方言對照器（PowerShell、zsh、bash、cmd） | 卡片依序淡入 | 無動畫 |
| `herodemo` | 首頁的打字＋拆解循環 | 打字、零件落下 | 靜態顯示第一個範例 |

所有元件的按鈕至少 36px 高（小按鈕），鍵盤可操作；播放器支援 ← → 方向鍵。進行中狀態用陰影而不是位移，避免窄螢幕溢出。

## 5. 與參考站的差異

| 項目 | 參考站 | 本站 |
|---|---|---|
| 互動元件 | loop、permsim、ctxcost | term、anatomy、fstree、pipeflow、pathfinder、rosetta、herodemo（移除用不到的三個） |
| 首頁 hero | 單欄標題 | 兩欄：標題＋打字拆解動畫 |
| 程式碼標籤 | 依語言 | 另外支援 `cmd`、`zsh` 標籤 |
| 選擇題 | 139 題，最長為正解 32% | 143 題，最長為正解 31.5% |
