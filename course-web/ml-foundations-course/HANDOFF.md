## 這卷新增的元件（`src/f-widgets.js` 最後一段）

| 元件 | 實際計算 |
|---|---|
| `fitline` | 拉 w、b 看殘差與 MSE；可逐步梯度下降、調學習率（會真的發散） |
| `kmeans` | 分配與移動逐步播放，顯示距離平方和 |
| `bandit` | 三台拉霸機、ε-greedy，用真的亂數 |
| `polyfit` | sin 波＋固定種子雜訊，最小平方＋L2，訓練與驗證誤差 |
| `threshold` | 閾值、混淆矩陣、accuracy、precision、recall、F1 |
