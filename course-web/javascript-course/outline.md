# 課程架構：JavaScript，看懂執行期到底發生什麼

> 版本：v1（2026-10-14）・ 依據：`research-notes.md`
> **10 個模組、38 個單元**，每單元 6–12 分鐘，總閱讀約 6 小時
> 對象：寫過一些程式（會 TypeScript 或其他語言），但 JavaScript 的執行期行為常常猜不準的人；零基礎也能讀，第一次出現的術語都有 popup
> 學完的狀態：看到一段 JS 能預測它印出什麼、在哪裡出錯、執行順序是什麼；知道哪些功能可以直接用、哪些要先查支援表

---

## A. 全站學習設計

### A-1 每個單元的固定結構

照 `course-web-neo-brutalism` 的 `content-rules.md`：3 件事 → 暖身回顧 → 比喻＋限制 → 心智模型 SVG → 正式定義 → 對照範例＋半成品 → 3 個常見錯誤 → 3 題練習（回想／應用／遷移）→ 三個重點 → 來源。

### A-2 全課主軸：遇到怪現象先問三個問題

每一課都回到同一組問題，側欄頂端常駐這張小卡：

```
1. 這是原始值，還是物件？        → 模組 1、3、4
2. 這個函式現在是被「誰」呼叫？    → 模組 5
3. 這段程式現在在執行，還是在排隊？ → 模組 6
```

### A-3 與既有規範、既有內容的取捨

| 項目 | 規範或既有內容 | 採用 | 理由 |
|------|------|------|------|
| 每課長度 | 6–12 分鐘 | 同 | — |
| 和 Notion 知識卷軸 | 同主題已有 16 課的 Notion 版 | **不搬文字**；網站版以「可操作」為主，每課的核心是一個讓讀者動手的元件 | 兩個版本互補；Notion 適合讀，網站適合玩 |
| 範例輸出 | 時效規則 | 所有「預測再驗證」的答案都用本機 Node.js 22.13 或 Chrome 實際跑出來的輸出 | research-notes 第 4 節已有一批 |
| 新功能 | 時效規則 | 主線只用 Node 22 與 Safari 17 以上都支援的功能；更新的功能加「新功能」貼紙＋支援表 | research-notes 第 3 節 |
| TypeScript 對照 | — | 每課最多一個「TypeScript 管不到」的小框 | 使用者寫 TS；只講執行期才看得到的差異 |
| 9-2、9-3、9-4 | 每課固定結構 | **新功能地圖、速查表、總複習用 reference 版型** | 查閱與總複習用 |
| 程式執行 | 不在主頁 `eval` | `runner` 元件用沙盒 iframe 執行 | 安全；讀者改壞程式也不影響頁面 |
| 外部套件 | Google Fonts、cdnjs | highlight.js（javascript、xml、bash） | 沿用參考站 |
| 建置 | 超過 5 個模組要分段 | `src/` 分段＋`scripts/build.sh` | 10 個模組 |

### A-5 互動元件與動畫（規則 13、14）

| 元件 | 做什麼 | 動畫？ | 出現位置 |
|------|------|------|------|
| `runner` 預測再執行 | 先選或寫下預測，再按「執行」在沙盒 iframe 跑程式，並排顯示「你的預測」與「實際輸出」；可以改程式再跑 | 靜態 | 幾乎每一課 |
| `floatbits` 浮點數拆解器 | 輸入一個數字，看它的 64 個位元（符號、指數、尾數）與實際存下來的值 | 靜態，輸入即時更新 | 1-2 |
| `refviz` 參考圖 | 逐行執行一段程式，左邊是變數、右邊是物件，箭頭顯示誰指向誰 | 逐步（狀態真的在變） | 4-1、4-2 |
| `coerce` 轉型探索器 | 選左值、右值、運算子，看每一步轉型與結果 | 靜態 | 3-1、3-3 |
| `mutator` 改不改原陣列 | 對同一個陣列按不同方法，看原陣列與回傳值有沒有變 | 靜態 | 4-4 |
| `thisfinder` this 判定器 | 選一種呼叫寫法，依序亮起四條規則，停在命中的那條 | 靜態 | 5-3 |
| `protochain` 原型鏈查找 | 輸入屬性名，看它一層一層往上找，在哪一層找到 | 逐步（查找真的在發生） | 5-4 |
| `loopsim` 事件迴圈模擬器 | 呼叫堆疊、微任務、任務三欄，逐步或自動播放一段程式 | **動畫**，可逐步；reduced-motion 時只能逐步 | 6-1、6-2 |
| `racer` 序列與平行 | 拉桿調整 3 個請求的耗時，比較逐一 await 與 Promise.all 的時間軸 | 時間軸動畫（時間真的在流逝） | 6-3 |
| `bubble` 事件冒泡 | 點巢狀元素，看事件從目標往外一層層觸發；可勾選 stopPropagation | 動畫（事件真的在傳遞） | 8-2 |
| `classify` 分類練習 | 拖曳或點選，把 API 分到「語言／瀏覽器／Node.js／兩者都有」 | 靜態 | 0-1、9-2 |
| `checklist` | 環境安裝、交付前檢查 | 靜態 | 0-2、9-1 |

概念流程（例如「錯誤沿呼叫堆疊往上傳」「模組只執行一次」）一律用靜態 SVG，不播放。

## B. 模組與單元

格式：`ID 標題（| 為斷點）`・目標・圖 1／圖 2・互動

### 模組 0　JavaScript 在哪裡跑（`--m0`）
- **0-1 語言、引擎|與執行環境**：分清 ECMAScript、引擎、瀏覽器與 Node.js。圖：三層架構；同一段程式在兩個環境的結果對照。互動：classify。
- **0-2 執行你的|第一支程式**：在瀏覽器 Console 與 Node.js 各跑一次。圖：Console 位置圖；`node 檔名.mjs` 流程。互動：checklist（安裝 Node LTS）。
- **0-3 讀懂錯誤訊息|與 console**：看懂錯誤種類、訊息、位置；`console.log`、`table`、`error`。圖：錯誤訊息解剖；三種 console 輸出對照。互動：runner（找出錯在第幾行）。

### 模組 1　值與型別（`--m1`）
- **1-1 七種原始值|與物件**：typeof 與它的兩個怪癖。圖：值的分類樹；typeof 對照表。互動：runner。
- **1-2 number 的真面目：|64 位元浮點數**：為什麼 `0.1 + 0.2 !== 0.3`、整數上限、金額用整數。圖：64 位元的三段；數線上的可表示點。互動：floatbits。
- **1-3 字串|與樣板字串**：不可變、方法回傳新字串、樣板字串與 Unicode 長度陷阱。圖：字串方法回傳新值；`length` 與字元數對照。互動：runner。
- **1-4 null、undefined|與「沒有值」**：兩者的來源與差別。圖：四種「沒有值」的出處；JSON 中的差異。互動：runner。

### 模組 2　變數與作用域（`--m2`）
- **2-1 let、const|與 var**：三種宣告的差別；const 鎖的是名字。圖：三者比較表圖；const 與物件內容。互動：runner。
- **2-2 提升|與暫時性死區**：名字先登記、值後到。圖：程式執行前的登記表；TDZ 時間軸。互動：runner（預測哪一行報錯）。
- **2-3 區塊、函式|與遮蔽**：作用域的巢狀與往外找。圖：巢狀作用域方框；查找方向。互動：runner。

### 模組 3　比較與轉型（`--m3`）
- **3-1 == 與 ===**：轉型規則與 NaN、Object.is。圖：`==` 決策流程；相等表熱圖。互動：coerce。
- **3-2 truthy、falsy、|?? 與 ?.**：八個 falsy、`||` 與 `??` 的差別。圖：falsy 清單；`||` vs `??` 對照。互動：runner。
- **3-3 加號、數字轉換|與表單輸入**：`+` 的字串相接、`Number` 與 `parseInt`。圖：由左往右的運算過程；三種轉換函式對照。互動：coerce。

### 模組 4　物件與陣列（`--m4`）
- **4-1 原始值是值，|物件是參考**：指定與傳參數複製的是什麼。圖：變數→物件箭頭；函式參數的兩種改法。互動：refviz。
- **4-2 淺複製、深複製|與解構**：展開、structuredClone、解構。圖：三種複製對照；解構對應圖。互動：refviz。
- **4-3 map、filter|與 reduce**：三個基本動作與 find、some、every。圖：生產線三台機器；reduce 累積過程。互動：runner。
- **4-4 會不會改到|原陣列**：sort 的兩個陷阱、toSorted 一族。圖：會改／不會改對照表；sort 字典順序。互動：mutator。
- **4-5 Map、Set|與分組**：什麼時候用 Map／Set、Set 新方法、Object.groupBy。圖：物件 vs Map；集合運算文氏圖。互動：runner。

### 模組 5　函式與物件模型（`--m5`）
- **5-1 函式是值、|箭頭函式與參數**：三種寫法、預設參數、剩餘參數、回呼。圖：三種寫法對照；回呼的呼叫關係。互動：runner。
- **5-2 閉包：|會記住環境的函式**：私有狀態、var 迴圈陷阱。圖：函式＋環境；共用變數 vs 各自一份。互動：runner。
- **5-3 this：|看是誰在呼叫**：四條規則與箭頭函式。圖：規則判定順序；方法脫鉤。互動：thisfinder。
- **5-4 原型鏈|與 class**：找不到就往上找；class、extends、#private。圖：原型鏈；class 與原型對應。互動：protochain。

### 模組 6　非同步（`--m6`）
- **6-1 事件迴圈：|一條執行緒與排隊**：同步、微任務、任務的順序；阻塞。圖：事件迴圈全圖；阻塞時間軸。互動：loopsim。
- **6-2 Promise：|未來才會有的值**：三種狀態、then 鏈、錯誤傳遞、四個組合工具。圖：狀態圖；四個組合工具對照。互動：loopsim（then 鏈）。
- **6-3 async／await：|序列與平行**：await 的意思、不小心變成一個一個等。圖：兩種時間軸；forEach 不會等。互動：racer。
- **6-4 fetch、錯誤|與取消**：res.ok、逾時、AbortController。圖：fetch 成功與失敗的分界；取消流程。互動：runner（模擬伺服器回應）。

### 模組 7　程式組織與品質（`--m7`）
- **7-1 ES 模組：|import 與 export**：具名與預設匯出、活的綁定、只執行一次。圖：模組相依圖；ESM vs CommonJS 表。互動：runner（多檔模擬）。
- **7-2 錯誤處理：|throw、catch 與 cause**：在能處理的那一層接；自訂錯誤。圖：錯誤沿堆疊往上；try 接不到非同步錯誤。互動：runner。
- **7-3 用 node:test|寫測試**：斷言、測試命名、看見失敗。圖：測試的輸入輸出表；紅綠循環。互動：runner（測試結果模擬）。
- **7-4 除錯：|斷點與開發者工具**：中斷點、逐步執行、看變數。圖：DevTools 面板位置；逐步執行按鈕對照。互動：checklist（除錯步驟）。

### 模組 8　在瀏覽器裡（`--m8`）
- **8-1 DOM：|網頁是一棵物件樹**：querySelector、textContent、createElement。圖：HTML 與 DOM 樹對照；三個動作。互動：runner（沙盒裡改 DOM）。
- **8-2 事件、冒泡|與事件委派**：事件往外傳、委派、target 與 currentTarget。圖：冒泡路徑；委派前後對照。互動：bubble。
- **8-3 表單、|innerHTML 與 XSS**：preventDefault、textContent 的安全性。圖：XSS 攻擊流程；安全與不安全寫法對照。互動：runner（同一個輸入兩種寫法）。
- **8-4 localStorage、|JSON 與驗證**：存讀、try／catch、驗證外部資料、版本號 key。圖：存讀流程；驗證失敗的退路。互動：runner。

### 模組 9　實戰與參考（`--m9`）
- **9-1 期末實作：|練球間歇計時器**：做一個「練 30 秒、休 15 秒、共 N 組」的計時網頁，可暫停、可取消、設定會保存。用到 4、5、6、7、8 模組。圖：程式分塊圖；狀態轉換圖。互動：checklist（交付前檢查）＋完整參考實作。
- **9-2 新功能地圖：|ES2024 到 ES2027**（reference 版型）：支援表、哪些現在能用。互動：classify（能用／要查表／還不能用）。
- **9-3 速查表**（reference 版型）：三個問題、轉型、陣列方法、this、事件迴圈的一頁整理。
- **9-4 總複習測驗**（reference 版型）：20 題，混合全部模組，每題都附解析並連回對應單元。
