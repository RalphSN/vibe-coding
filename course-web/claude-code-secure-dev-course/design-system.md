## 3. 字級與版面

- `html { font-size: calc(var(--font-scale, 1) * 100%) }`，字級 6 段：87.5／100／112.5／125／137.5／150%。
- 字級與側欄寬度在 `<head>` 的小 script 裡先套用，避免閃爍。
- 側欄：≥ 1280px 固定且可拖曳，224px–min(480px, 40vw)，預設 288px；< 1280px 為抽屜。
- 閱讀欄 `--measure: 42rem`。

## 4. 與參考站不同的地方（skill 要求）

| 位置 | 本站做法 |
|---|---|
| 連結 hover | 只換底色 `--highlight`，底線粗細不變；hover 寫在 `(hover: hover) and (pointer: fine)` 內 |
| 側欄模組收合 | `.collapse` grid-rows `0fr ↔ 1fr`，收合後才 `visibility: hidden` |
| 術語 popup | 可被 hover（100ms 寬限）、150ms 延遲顯示、`Esc` 關閉、有退場淡出；有連結時是非模態 popover |
| tooltip、選單、抽屜遮罩 | `data-state="open|closing|closed"`，退場動畫跑完才隱藏 |
| `details.reveal` | `::details-content` ＋ `interpolate-size` 高度動畫，內容淡入 |
| 分頁 | 舊面板淡出、新面板淡入並水平滑入 8px |
| 選擇題 | 每個選項都有 `why`；選項依題目 key 固定打亂；送出後列出全部解析，選中的在最上面 |
| 標題換行 | 資料用 `|` 標斷點 → `.phrase` ＋ `.word`；仍有孤行時 `--fit` 縮字到 80% |
| 標題裡的英文詞組 | 14 字元內的（`auto mode`、`GitHub Actions`）用不換行空白黏住；更長的允許在空白處換行 |
| 按鈕 | `white-space: nowrap`，文字控制在 8 字內 |

## 4.1 驗證後補上的調整（2026-10-02）

| 問題 | 調整 |
|---|---|
| 字級 150% 時，288px 的目錄把標題擠到斷字 | 沒拖過把手時，預設寬度 = 288px × 字級（仍受 224–480px 限制） |
| 1280px＋大字級時，右側本課目錄把內容欄擠到約 450px | 字級 ≥ 137.5% 時收起右側目錄（`data-large-text`） |
| 模組卡片欄數看視窗寬度，字級放大時卡片太窄 | 改用 container query，依容器寬度（rem）決定 1／2／3 欄 |
| 768px＋大字級時頂部列溢出 | 頂部列的字級按鈕只在 ≥ 1100px 顯示，較窄時收進「Aa」選單 |
| 上一課／下一課的編號單獨成一行 | 編號和標題的第一個詞組放在同一個 `.phrase` |
| 換課動畫的 transform 讓 popup 的 fixed 定位偏移 | `animationend` 後移除 class；popup 定位後量一次實際位置並補正 |

## 4.2 使用者回報的版面問題（2026-10-02 第二輪）

| 問題 | 調整 |
|---|---|
| 側欄與拖曳線的頂端插進頂部列 | 頂部列高度不再寫死 64px：啟動、縮放、改字級時量一次寫回 `--topbar-h`，另有 ResizeObserver（border-box） |
| 手機上漢堡選單、深色模式按鈕被壓窄或擠出畫面 | 頂部列子項 `flex: none`，只有搜尋框可伸縮；圖示按鈕固定 44×44；右側與底部多留 4px 給硬陰影 |
| 搜尋框比按鈕高 7px | 輸入框 `display: block; height: 44px; line-height: 1.2` |
| 視窗縮小再放大後，目錄寬度卡在 224px | resize 時用偏好值重算，不用目前被夾住的值 |
| 目錄標題可用寬度太窄 | 縮小縮排與間距、細捲軸；標題欄 `flex: 1` |
| 首頁、模組頁右側留一欄空白 | 沒有本課目錄的頁面用兩欄版面（`.layout.no-toc`） |
| 單元資訊列在手機上斷得零散 | 進度條與「已完成 N / M」綁成一組不拆開 |
| 手機上學習目標、定義被長的英文或 code 撐破 | grid／flex 子項加 `min-width: 0`，定義的英文名稱可在任意處換行 |

## 4.3 第三輪：對齊（2026-10-02）

| 問題 | 原因 | 調整 |
|---|---|---|
| 捲到頁尾時，目錄的拖曳線蓋過頁尾 | 把手用 `position: fixed; bottom: 0`，不知道頁尾在哪 | 把手和側欄放在同一個 grid 格子、一起 sticky、同高；平常透明，hover 時才在側欄邊框的位置變色 |
| 0-1、3-3 的時間軸頭尾凸出圓點 | 線段座標隨手寫，沒對準第一個與最後一個圓心 | 線段改成從第一個圓心到最後一個圓心 |
| 1-1、5-2、7-2 有線段離圖形 3–90px | 同上 | 端點改到方框邊緣、文字頂端 |

第四輪（文字）：6-3「測試要一直全過」壓到兩側方框 → 分兩行放在中間空隙；2-3「風險／區」單字成行 → 合成一行；2-2「測試報告、CHANGELOG」貼到框線 → 分兩行；4-2、5-2 的線段碰到文字 → 和文字之間留 6px 以上空隙。

SVG 文字規則：文字要不在圖形外，要不完整在圖形內並留至少 4px 內距；和線段之間至少 3px；文字之間不重疊；手動分行時每行至少 2 個字（SVG 的 `<text>` 不會自動換行，網頁的換行規則管不到它）。

SVG 規則：連接線的每個端點都要落在方框邊緣、圓內、箭頭或文字上（指向文字時留 6–10px 空隙，不要碰到字）；刻意不接任何東西的線（座標軸、示意用的網）加 `data-free-ends="原因"`。驗證腳本會跳過有標註的線，其餘懸空的端點一律報錯。

## 5. 動畫

`--dur-micro 120ms`、`--dur-comp 240ms`、`--dur-page 360ms`；位移用 `--ease-snap`，高度用 `--ease-mech`。只動 `transform`、`opacity`、顏色；例外是摺疊區高度與 SVG `stroke-dashoffset`。`prefers-reduced-motion` 時關閉位移與高度動畫，保留 120ms 內的淡入淡出。
