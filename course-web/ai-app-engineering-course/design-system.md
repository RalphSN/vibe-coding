# 設計系統：AI 系列・第一部｜AI 應用工程

> 版本：v1（2026-10-22）・ 基底：`course-web-neo-brutalism` 的 token（`design-tokens.md`），引擎沿用 `adhd-planning-course/src`（2026-10-19 版）
> 視覺方向：「工地告示牌 × 手作貼紙本」，加上本書自己的母題：**API 請求單據**。

## 1. 本書的藝術指導

| 元素 | 做法 | 為什麼 |
|------|------|------|
| 品牌 | 藍底 `{ }` 方塊（`--m2`）＋「AI 應用工程」＋黃色「第一部」卷標 | `{ }` 是 JSON 請求的括號，一眼看出「用程式呼叫 AI」；卷標讓七本書看得出是同一套 |
| 首頁主視覺 | 左邊深色「請求單」（真正的 Messages API JSON），右下白色「回應卡」逐段打字 | 串流是真實機制，可以動；請求單和回應卡錯開旋轉，保留手作貼紙感 |
| 主標 | 「模型只寫字，／其他全靠／**你的程式**」 | 全書主軸一句話講完；每個詞組 ≤ 6 字，任何寬度都不會拆詞 |
| 全書主軸 | 「一個請求的旅程」五色貼紙：你的程式 → 請求 → 模型 → 回應 → 你的程式 | 每課標出自己在旅程哪一段 |
| 系列選單 | 頂部列「AI 系列 ▾」下拉（≥ 768px）、側欄頂端清單（< 768px） | 七本書互相連結；還沒做的卷顯示「製作中」、不給連結 |

## 2. Token

沿用參考站，**沒有新增顏色 token**。本書用到的組合：

| 用途 | 組合 |
|------|------|
| 品牌括號 | 黑字 × `--m2` |
| 目前所在的卷 | 黑字 × `--primary` |
| 「必填」標籤 | 黑字 × `--warning` |
| 驗證通過／失敗 | 黑字 × `--success`／`--danger-soft` |
| SSE 原始文字 | `--code-ink` × `--code-bg`；`event:`、`data:` 用 `--m0`；`text_delta` 行用 `#A8F0B4` |
| 工具迴圈三條泳道 | 你的程式 `--m0`、Claude `--m2`、工具 `--m4`（黑字） |

## 4. 元件清單

共用（沿用參考站）：按鈕、徽章、進度條、提示框（含本書新增的 `lab`「動手做」）、術語 popup、程式碼區塊、對照器、分頁、測驗、表格、檢查清單、`classify`、圖片放大。

本書新增的互動元件（規格寫在 `src/f-widgets.js` 每個元件上方的註解）：

| 元件 | 讀者做什麼 | 動畫？ |
|------|------|------|
| `reqbuilder` | 勾選欄位，即時看 JSON 請求與「會不會 400」 | 靜態 |
| `tokenmeter` | 輸入文字看示意切法（明講不是真的 tokenizer） | 靜態 |
| `costcalc` | 選模型、拉請求數／輸入／輸出／快取（對數刻度），看每次與每月成本 | 靜態 |
| `ssestream` | 送出、逐事件、停止、斷線；原始 SSE 與畫面同步 | **動畫**（資料真的逐筆流過）；reduced-motion 時只能逐事件 |
| `schemacheck` | 改模型輸出的 JSON，看哪一欄過不了 schema | 靜態 |
| `toolloop` | 逐步走過 tool_use → 執行 → tool_result，可切到「工具失敗」情境 | 步進（使用者按） |
| `vecplot` | 拖動查詢點，看 cosine／點積／歐氏距離的前 k 名，可加過濾 | 靜態（拖曳即時更新） |
| `chunker` | 拉塊大小與重疊、切換切法，看答案有沒有被切斷 | 靜態 |
| `ragtrace` | 逐站看檢索、rerank、組 prompt、回答與引用，可切情境 | 步進 |
| `evalgrid` | 自己先判合格，再和精確比對、規則、LLM 裁判比一致度 | 靜態 |
| `knobs` | 通用拉桿：課程資料提供 `compute()`，顯示長條結果 | 靜態 |
| `herodemo` | 首頁：請求單＋串流回應 | 動畫（串流）；reduced-motion 顯示完成狀態 |

## 5. 版面決策

- 元件內的 grid 一律 `grid-template-columns: minmax(0, 1fr)`：長 `pre` 不會撐破元件（2026-10-22 工具迴圈第三欄被裁掉，因此加上）。
- `reqbuilder`、`ssestream`、`schemacheck`、`vecplot` 用 container query：元件寬 ≥ 40rem 才左右並排；課文欄寬 42rem 扣掉內距後通常是上下排。
- 首頁標題詞組 ≤ 6 字，800px 寬時曾出現「讀／字」拆行，已改寫。
